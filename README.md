# Munson’s Garage Website

## Project Overview
This project is a website created for Munson’s Garage, a car garage business. The purpose of the website is to give the business a professional online presence where customers can learn about the garage, view services, and find contact information.

## Purpose
The goal of this project was to design a clean and organized business website for an auto repair garage. The website helps customers understand what services are offered and makes the business look more professional online.

## Features
- Professional homepage
- About the business section
- Services section
- Contact information
- Clean navigation
- Business-focused layout
- Mobile-friendly design

## Skills Demonstrated
- Web design
- Front-end development
- Layout organization
- Business website planning
- Content organization
- GitHub project management
- Professional presentation

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub

## What I Learned
While working on this project, I learned how to create a website for a real business purpose. I practiced organizing service information, designing a professional layout, and making the website easy for customers to understand. This project also helped me improve my ability to build websites that support a company’s online presence.

## Future Improvements
In the future, I would like to improve this website by adding more service details, customer reviews, a photo gallery, and a working contact form. I would also like to continue improving the design and mobile responsiveness.
